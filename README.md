# Colored Slots
This mod allows changing the color of the slots in the inventory and placing icons.

## Dependencies
- [YetAnotherConfigLib](https://modrinth.com/mod/yacl/version/3.9.6+26.2-fabric)
- [FabricAPI](https://modrinth.com/mod/fabric-api/version/0.157.0+26.2)
